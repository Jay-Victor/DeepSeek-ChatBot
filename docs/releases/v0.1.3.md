把 [deepseek-ai/chat-demo](https://github.com/deepseek-ai/chat-demo) 0.1.1 装进 Android 的第四个可安装版本：新增输入框上下文占用环，并保留 v0.1.2 的思考自动折叠、单按钮、推挤式侧边栏与关于页更新检查。

## 应用

- 包名 `com.deepseekchatbot`，`versionCode 4`
- minSdk 26 / targetSdk 36 / compileSdk 36
- Release APK 5.31 MB，v2 签名

## 功能（来自上游）

多会话与自动标题、编辑提问 / 重新生成 / 消息分支、流式回答、深度思考、智能搜索与来源引用、附件上传（粘贴与拖拽）、语音输入与朗读、Markdown / 代码高亮 / KaTeX 公式 / Mermaid 图表、中英文、浅色深色、ZIP 历史导入导出。

## 壳补的能力

- 输入框功能行新增 1M 上下文占用环：用 DeepSeek-V4 分词器统计当前分支的文本 token，每个回合结束后更新，切换会话或分支也会重算
- 服务端 `usage` 用于校准系统模板、工具声明与附件开销；点击环可查看已用 / 窗口、百分比、对话文本、系统与模板，以及上次请求的输入与输出
- 附件、`read_link` 网页正文由服务端解析或解密，本地只能按文本估算，详情会标注；纯文本且拿到 `usage` 时按服务端实测校准
- 其余沿用 v0.1.0–v0.1.2：固定 `appassets` origin、麦克风授权、文件选择、ZIP 导出走 SAF、Custom Tabs 外链、返回键分层退出、状态栏反色、安全区与键盘避让、思考内容自动折叠、输入框单按钮、推挤式侧边栏、关于页更新检查

## 安装

```bash
adb install -r DeepSeekChatBot-v0.1.3-release.apk
```

首次启动在「设置 → 数据管理」填入自己的 DeepSeek API Key；Key 只存本机 WebView 的 localStorage，不进云备份。

## 已知限制

- 上下文环对附件、网页阅读只能本地按文本估算；纯文本会话在有 `usage` 后校准，误差最小
- 1M 窗口下普通会话占比很低；环内使用 2% 最小可见弧度，精确数值以点击后的详情为准
- 后台 / 锁屏时 WebView 被系统节流，长时间生成可能中断（未实现前台服务）
- 运行中切换系统深浅色需重启应用；应用内「设置 → 主题」即时生效
- 更新检查依赖 GitHub 公开 API，未登录限流 60 次/小时/IP；频繁打开或切回前台可能触发限流，此时「关于」页会提示检查失败，可稍后重试

## English

Fourth installable build of chat-demo 0.1.1 in a thin Kotlin WebView shell. This release adds a context-usage ring in the composer: it counts the current branch with the DeepSeek-V4 tokenizer against a 1M-token window, refreshes after each turn, and calibrates system/template/attachment overhead with server-reported usage. Tapping the ring shows the exact numbers and the last request's input/output tokens. Attachments and read-link pages are server-parsed, so they are marked as local estimates. Everything from v0.1.0–v0.1.2 is retained, including the thinking-collapse switch, single voice/send/stop button, push-style mobile sidebar, and About-page update checks. Bring your own DeepSeek API key (stored locally only, excluded from cloud backup). Install with `adb install -r`; minSdk 26. MIT licensed, upstream notice kept in `web/LICENSE`.
