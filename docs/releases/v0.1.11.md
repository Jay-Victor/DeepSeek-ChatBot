把 [deepseek-ai/chat-demo](https://github.com/deepseek-ai/chat-demo) 0.1.3 装进 Android 的第十二个可安装版本：语音改为按住说话，附件入口展开相册面板，更新提示直达「关于」。

## 应用

- 包名 `com.deepseekchatbot`，`versionCode 12`
- minSdk 26 / targetSdk 36 / compileSdk 36
- Release APK 5.34 MB，v2 签名

## 功能（来自上游）

多会话与自动标题、编辑提问 / 重新生成 / 消息分支、流式回答、深度思考、智能搜索与来源引用、附件上传（粘贴与拖拽）、语音输入与朗读、Markdown / 代码高亮 / KaTeX 公式 / Mermaid 图表、中英文、浅色深色、ZIP 历史导入导出。

## 壳补的能力

- **语音输入**：输入框右侧改为圆圈声波入口；点击切到「按住说话」，按住开始录音、松手转写并直接发送，上滑越过阈值变为红色「松开取消」；录音浮层显示蓝色渐变、提示语与实时频谱，右侧键盘按钮切回文本输入
- **添加附件**：输入框附件入口改为圆圈加号；点击后输入框上滑，展开手机最近照片横排与「拍照 / 相册 / 文件」三个按钮。最近照片通过 MediaStore 读取，拍照调用系统相机，相册打开系统图片选择器
- **相册权限**：首次打开申请照片权限（Android 13+ 使用 `READ_MEDIA_IMAGES`，14+ 支持仅选择部分照片）；拒绝后照片条显示重试提示，拍照 / 相册 / 文件仍可使用
- **更新提示**：检测到新版本后，聊天页提示整条可点，直接打开「设置 → 关于」，不再跳转 Release 网页；键盘 Enter / 空格也可触发
- **自动朗读开关**：改为细线喇叭，开启为双声波，关闭为同形喇叭加叉号
- 其余沿用 v0.1.0–v0.1.10：移动端会话搜索、置顶与多选、自动朗读、应用内下载安装更新、上下文占用环、思考内容自动折叠、固定 `appassets` origin、麦克风授权、文件选择、附件打开与 SAF 下载、ZIP 导出、Custom Tabs 外链、返回键分层退出、状态栏反色、安全区与键盘避让、推挤式侧边栏

## 安装

```bash
adb install -r DeepSeekChatBot-v0.1.11-release.apk
```

首次启动在「设置 → 数据管理」填入自己的 DeepSeek API Key；Key 只存本机 WebView 的 localStorage，不进云备份。

## 已知限制

- 最近照片需要相册权限；拒绝后照片条不可用（显示重试），拍照 / 相册 / 文件不受影响
- 按住说话在松手后直接发送转写结果；识别失败只提示，不会发送空消息
- 超过 4096 像素的动图在上传前缩放时只保留一帧，动效会丢失（上游行为）
- PDF 打开依赖系统查看器；没有可用的 PDF 应用时会弹出保存位置选择
- 后台 / 锁屏时 WebView 被系统节流，长时间生成可能中断（未实现前台服务）
- 运行中切换系统深浅色需重启应用；应用内「设置 → 主题」即时生效
- 应用内更新需要访问 GitHub 资产；受限网络可能下载失败，此时可用「在浏览器中下载」

## English

Twelfth installable build of chat-demo 0.1.3 in a thin Kotlin WebView shell. Voice input now uses a circled sound-wave button: tapping switches to Hold to talk, holding records, releasing transcribes and sends automatically, swiping up cancels, and a blue-gradient overlay shows a live spectrum. The attachment button is a circled plus that slides the composer up and reveals recent photos plus Camera / Photos / Files; recent photos come from MediaStore and camera capture uses the system camera. Photo permission is requested on first use, and denying it only disables the photo strip. The new-version prompt now opens Settings → About instead of the release page. The auto-read toggle uses a line-style speaker icon. Everything from v0.1.0–v0.1.10 is retained. Bring your own DeepSeek API key (stored locally only, excluded from cloud backup). Install with `adb install -r`; minSdk 26. MIT licensed, upstream notice kept in `web/LICENSE`.
