v0.1.17 把 chat-demo 装进 Android 后加入「外观」：自定义图片 / 视频背景、蒙层与模糊、可拖动主题色，并把「主题」改为分段控制器的「模式」。

## 应用

- 包名 `com.deepseekchatbot`，`versionCode 18`
- minSdk 26 / targetSdk 36 / compileSdk 36
- Release APK 5.36 MB，v2 签名

## 本版变更

- 设置新增「外观」分组：图片 / 视频自定义背景，两类各保留一份，切换不用重新选择；预览窗实时显示蒙层与模糊
- 背景效果：蒙层浓度 0%–100%（默认 20%，100% 完全遮住）与 0–24px 模糊；视频背景静音循环，切后台自动暂停
- 自定义主题色：色相拖动条即时覆盖按钮、链接、用户气泡、选中态等整套品牌色；按 WCAG 对比度自动切换主色上的黑 / 白文字，可恢复默认 DeepSeek 蓝
- 有背景时聊天区、顶栏、输入框与侧边栏使用 82%–90% 半透明面板，壁纸透过面板可见
- 通用设置的「主题」改名「模式」，浅色 / 深色 / 跟随系统改为分段控制器
- 设置分组增加到六个：通用设置 → 外观 → 身份声明 → 上下文与压缩 → 数据管理 → 关于
- 背景媒体由壳通过 SAF 选择后复制到应用私有目录，以同源 `/userbg/` 地址提供并支持 Range（206），视频 seek / loop 稳定；浏览器回退到独立 IndexedDB

## 功能（来自上游）

多会话与自动标题、编辑提问 / 重新生成 / 消息分支、流式回答、深度思考、智能搜索与来源引用、附件上传、语音输入与朗读、Markdown / 代码高亮 / KaTeX / Mermaid、中英文、浅色深色、ZIP 历史导入导出。

## 壳补的能力

- 返回键、状态栏配色、安全区与键盘避让、麦克风、文件选择、SAF 下载、附件打开、Custom Tabs 外链、应用内更新等沿用 v0.1.0–v0.1.16
- 新增 `pickBackground` / `backgroundInfo` / `clearBackground` 桥与 `BackgroundStore`：图片与视频各保留一份，图片上限 30MB、视频上限 100MB
- `shouldInterceptRequest` 优先处理 `/userbg/`，按 `Range` 返回 206 与 `Content-Range`；背景文件不经过 IndexedDB，避免 WebView 读回 SAF 文件 `size=0`
- 未新增系统权限：背景选择走 `ACTION_OPEN_DOCUMENT` 自带的读授权

## 安装


## 已知限制

- 自定义背景只作用于内容区，状态栏与导航栏仍是主题底色（原生壳给 WebView 留系统栏 inset）
- 蒙层默认 20%；设为 0 时过亮的壁纸可能降低文字可读性，可调高蒙层或模糊
- 视频背景持续解码，耗电高于纯色背景，低端机可能掉帧；模糊建议不超过 8px，格式取决于系统 WebView（H.264 MP4 / WebM 较稳，HEVC / MOV 视设备而定）
- 外观设置是设备级设置，不随 ZIP 历史导出 / 导入迁移；卸载应用会删除背景文件
- 主题色只调整色相，饱和度与明度沿用 DeepSeek 品牌色阶；极黄 / 极绿等色相会自动改用深色文字
- 设置分组增加到六个，移动端横向导航需要左右滑动才能到达「数据管理 / 关于」

## English

v0.1.17 adds an Appearance section: pick an image or video wallpaper (one of each is kept), tune a 0–100% overlay (20% default) and 0–24px blur, and drag a hue slider to recolour buttons, links and bubbles; primary text switches between black and white by contrast, with one-tap reset to DeepSeek blue. Video wallpapers play muted and loop, and pause in the background. With a wallpaper active, the chat area, header, input and sidebar become translucent. The old Theme row is now a segmented Mode control (Light / Dark / System), and settings grow to six sections. Wallpaper media is copied by the native shell into private storage and served over a same-origin `/userbg/` URL with Range support; the browser falls back to a separate IndexedDB. Appearance stays on-device and is not included in ZIP export/import. minSdk 26, MIT licensed, upstream notice kept in `web/LICENSE`.
