v0.1.16 为助手加入可切换的身份声明：设置里可建多套方案，聊天页顶栏按会话切换。

## 应用

- 包名 `com.deepseekchatbot`，`versionCode 17`
- minSdk 26 / targetSdk 36 / compileSdk 36
- Release APK 5.35 MB，v2 签名

## 本版变更

- 设置新增「身份声明」分组：可创建多套方案，每套由姓名与设定组成，发送时拼成「你是{姓名}。{设定}」作为系统提示；内置方案可编辑、不可删除，最多 20 套，姓名最多 20 字、设定最多 2000 字
- 聊天页顶栏新增身份切换器：移动端在侧边栏按钮右侧，桌面在会话标题旁；菜单列出方案、当前项打勾，并提供「管理身份声明」入口
- 每个会话单独记录所用方案，切换只影响之后的请求；新会话继承设置里的默认方案；欢迎页切换的是新会话默认方案
- 上下文占用的「系统与模板」与压缩预算按当前会话的身份声明统计；身份方案改动后占用环自动重算
- 身份切换器计入原生返回键的弹层状态，菜单打开时按返回只关闭菜单
- 桌面欢迎页右上角、桌面会话标题旁均提供切换入口；移动端沿用顶栏

## 已知限制

- 身份声明是设备级设置，不随 ZIP 历史导出 / 导入迁移；导入的会话回到内置身份
- 自动标题与首条回复共用同一请求，标题也会带上当前身份
- 切换身份不会改写已有历史，旧回复仍由之前的身份生成；建议在新会话或下一轮切换
- 设置分组增加到五个，移动端横向导航需要左右滑动才能到达「数据管理 / 关于」
- 设定的自由文本若包含过强的格式指令，可能影响工具调用、思考块或自动标题的表现

## English

v0.1.16 adds switchable identity statements. Create multiple name + setting profiles in Settings; each is sent as `你是{name}。{setting}`. Switch per chat from the header (next to the sidebar button on mobile, beside the title on desktop); new chats inherit the default profile chosen in Settings. The system prompt, context-usage estimate and compression budget all follow the selected profile. Profiles are device-level and are not included in ZIP export/import; imported chats use the built-in identity. minSdk 26, MIT licensed, upstream notice kept in `web/LICENSE`.
