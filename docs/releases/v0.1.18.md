v0.1.18 修复 v0.1.17 的自定义主题色对比度：浅色模式下把色相拖到黄 / 绿等亮色时，链接、选中项与品牌文字现在保持可读。外观功能与 v0.1.17 相同。

## 应用

- 包名 `com.deepseekchatbot`，`versionCode 19`
- minSdk 26 / targetSdk 36 / compileSdk 36
- Release APK 5.36 MB，v2 签名

## 本版变更

- 主题色覆盖层新增 `brand-text` 与侧栏选中项反色的对比度收口：浅色底上按 4.5:1 自动调暗，深色底上自动调亮
- 侧栏 appName、回复标题图标、上下文占用环与朗读波形改用可读的 `brand-text`；主按钮 / 气泡等填充仍使用鲜艳的主色，并按对比度自动选择黑 / 白文字
- 其余外观能力沿用 v0.1.17：图片 / 视频背景（各保留一份）、蒙层 0%–100%（默认 20%）、0–24px 模糊、静音循环视频、分段「模式」，以及壁纸存在时的半透明面板

## 功能（来自上游）

多会话与自动标题、编辑提问 / 重新生成 / 消息分支、流式回答、深度思考、智能搜索与来源引用、附件上传、语音输入与朗读、Markdown / 代码高亮 / KaTeX / Mermaid、中英文、浅色深色、ZIP 历史导入导出。

## 壳补的能力

- 返回键、状态栏配色、安全区与键盘避让、麦克风、文件选择、SAF 下载、附件打开、Custom Tabs 外链、应用内更新等沿用 v0.1.0–v0.1.17
- 背景媒体继续由 `BackgroundStore` 复制到私有目录，以同源 `/userbg/` 提供并支持 Range（206）；本版只改 Web 层主题色对比度，原生无新增权限或接口

## 安装

```bash
adb install -r DeepSeekChatBot-v0.1.18-release.apk
```

首次启动在「设置 → 数据管理」填入自己的 DeepSeek API Key；Key 只存本机 WebView 的 localStorage，不进云备份。

## 已知限制

- 自定义背景只作用于内容区，状态栏与导航栏仍是主题底色（原生壳给 WebView 留系统栏 inset）
- 蒙层默认 20%；设为 0 时过亮的壁纸可能降低文字可读性，可调高蒙层或模糊
- 视频背景持续解码，耗电高于纯色背景，低端机可能掉帧；格式取决于系统 WebView（H.264 MP4 / WebM 较稳，HEVC / MOV 视设备而定）
- 外观设置是设备级设置，不随 ZIP 历史导出 / 导入迁移；卸载应用会删除背景文件
- 主题色只调整色相，饱和度与明度沿用 DeepSeek 品牌色阶；亮色相下链接文字会自动调暗，因此可能与色块本身不完全同色

## English

v0.1.18 fixes accent contrast in light mode. Yellow / green hues used to leave links, the Settings Reset action, the selected sidebar row and the brand text hard to read on a light page; they now keep 4.5:1, while primary fills stay vivid and switch between black and white text by contrast. The app name, title icon, context ring and read-aloud waveform painted on the page background now use the readable brand-text alias. All appearance features from v0.1.17 are unchanged: image / video wallpapers, a 20%-default overlay, 0–24px blur, muted looping video, the segmented Mode control and translucent panels. Appearance stays on-device and is not included in ZIP export/import. minSdk 26, MIT licensed, upstream notice kept in `web/LICENSE`.
