v0.1.14 修复 v0.1.13 的移动端设置导航重叠，其余功能与 v0.1.13 相同。

## 应用

- 包名 `com.deepseekchatbot`，`versionCode 15`
- minSdk 26 / targetSdk 36 / compileSdk 36
- Release APK 5.34 MB，v2 签名

## 本版修复

- 现象：设置弹窗中「通用设置 / 上下文与压缩 / 数据管理 / 关于」在窄屏或较大字号下文字与图标重叠
- 原因：v0.1.13 为在单行放下四个分组，把移动端导航改成可收缩（`min-width: 0` + `white-space: nowrap`）；四项内容宽度超过容器，Flex 把每项压到内容宽度以下，文字溢出到相邻项
- 修复：移动端导航改为 2×2 网格，每项占一半宽度，不再压缩到内容宽度以下；长标签允许换行，图标不收缩
- 验证：390×844 视口下以 14 / 16 / 22px 字号复验，均无重叠；22px 时「上下文与压缩」换成两行
- 其余功能与 v0.1.13 相同

## 功能（来自上游）

多会话与自动标题、编辑提问 / 重新生成 / 消息分支、流式回答、深度思考、智能搜索与来源引用、附件上传、语音输入与朗读、Markdown / 代码高亮 / KaTeX / Mermaid、中英文、浅色深色、ZIP 历史导入导出。

## 壳补的能力

- 上下文与压缩、设置分组与占用卡片沿用 v0.1.13，本次仅调整移动端设置导航布局
- 返回键、状态栏配色、安全区与键盘避让、麦克风、文件选择、SAF 下载、附件打开、Custom Tabs 外链、应用内更新等沿用 v0.1.0–v0.1.13

## 安装

```bash
adb install -r DeepSeekChatBot-v0.1.14-release.apk
```

首次启动在「设置 → 数据管理」填入自己的 DeepSeek API Key；Key 只存本机 WebView 的 localStorage，不进云备份。

## 已知限制

- 超大字号下长标签会换成两行，这是为了避免与相邻分组重叠
- 压缩摘要会产生额外的模型请求；压缩目标是软目标，最近一轮本身过大时可能达不到
- 压缩只保留单条记录：在覆盖点之前切分支会让摘要失效；在另一条分支再压缩会覆盖前一条
- ZIP 导入导出不携带压缩摘要，导入后回到完整上下文

## English

v0.1.14 fixes the overlapping settings tabs introduced in v0.1.13 on narrow screens or with larger text. The mobile navigation is now a 2×2 grid instead of a single shrinkable row, so each label keeps its own width and long labels wrap; all four sections stay visible. Verified at 390×844 with 14 / 16 / 22px text without overlap. Compression, the usage popover, and the shell capabilities are unchanged from v0.1.13. Install with `adb install -r`; minSdk 26, MIT licensed, upstream notice kept in `web/LICENSE`.
