把 [deepseek-ai/chat-demo](https://github.com/deepseek-ai/chat-demo) 0.1.1 装进 Android 的第八个可安装版本：收紧输入框底栏，并让「深度思考 / 智能搜索」在窄屏或大字体下保留文字。

## 应用

- 包名 `com.deepseekchatbot`，`versionCode 8`
- minSdk 26 / targetSdk 36 / compileSdk 36
- Release APK 5.32 MB，v2 签名

## 功能（来自上游）

多会话与自动标题、编辑提问 / 重新生成 / 消息分支、流式回答、深度思考、智能搜索与来源引用、附件上传（粘贴与拖拽）、语音输入与朗读、Markdown / 代码高亮 / KaTeX 公式 / Mermaid 图表、中英文、浅色深色、ZIP 历史导入导出。

## 壳补的能力

- 输入框底栏收紧：「深度思考 / 智能搜索」高度 34→32、内边距 12→10、按钮间距 10→8，整体向左边框靠拢；上下文占用环、附件、发送 / 停止按钮间距 4→2，去掉发送键额外的 6px 左边距，整体向右边框靠拢
- 空间不足时不再隐藏开关文字：改为收起图标、保留「深度思考 / 智能搜索」，并按按钮的真实外框判断是否需要紧凑布局；字体晚于首帧加载时会重新测量，窄屏或系统大字体下也不会只剩图标
- 其余沿用 v0.1.0–v0.1.6：移动端会话搜索、底部浮动「新建」、会话顶栏常驻新建、应用内下载安装更新、上下文占用环、思考内容自动折叠、固定 `appassets` origin、麦克风授权、文件选择、ZIP 导出走 SAF、Custom Tabs 外链、返回键分层退出、状态栏反色、安全区与键盘避让、推挤式侧边栏

## 安装

```bash
adb install -r DeepSeekChatBot-v0.1.7-release.apk
```

首次启动在「设置 → 数据管理」填入自己的 DeepSeek API Key；Key 只存本机 WebView 的 localStorage，不进云备份。

## 已知限制

- 底栏空间确实不够时会隐藏两个开关的图标、只保留文字（不会隐藏文字）；这是为了在窄屏和大字体下仍能读出开关含义
- 会话搜索只在移动端侧边栏；桌面端保持原来的全宽新建按钮与列表
- 后台 / 锁屏时 WebView 被系统节流，长时间生成可能中断（未实现前台服务）
- 运行中切换系统深浅色需重启应用；应用内「设置 → 主题」即时生效
- 应用内更新需要访问 GitHub 资产；受限网络可能下载失败，此时可用「在浏览器中下载」
- 更新检查与资产下载依赖 GitHub 公开 API，未登录限流 60 次/小时/IP

## English

Eighth installable build of chat-demo 0.1.1 in a thin Kotlin WebView shell. The composer footer is tightened: the deep-thinking and web-search toggles are slightly smaller and closer to the left edge, while the context ring, attachment and send/stop controls sit closer together and closer to the right edge. When space is short (narrow screen or a wide system font), the toggles now hide their icons and keep their labels instead of hiding the words, and the compact decision is re-measured after fonts load. Everything from v0.1.0–v0.1.6 is retained, including mobile session search, the floating New button, the persistent header action, in-app updates, the context ring, SAF export, Custom Tabs and three-level back handling. Bring your own DeepSeek API key (stored locally only, excluded from cloud backup). Install with `adb install -r`; minSdk 26. MIT licensed, upstream notice kept in `web/LICENSE`.
