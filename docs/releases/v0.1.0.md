把 [deepseek-ai/chat-demo](https://github.com/deepseek-ai/chat-demo) 0.1.1 原样装进 Android：上游前端产物 + 一层 Kotlin WebView 壳，不重写界面、不改协议。首个可安装版本。

## 应用

- 包名 `com.deepseekchatbot`，`versionCode 1`
- minSdk 26 / targetSdk 36 / compileSdk 36
- Release APK 4.53 MB，v2 签名

## 功能（来自上游）

多会话与自动标题、编辑提问 / 重新生成 / 消息分支、流式回答、深度思考、智能搜索与来源引用、附件上传（粘贴与拖拽）、语音输入与朗读、Markdown / 代码高亮 / KaTeX 公式 / Mermaid 图表、中英文、浅色深色、ZIP 历史导入导出。

## 壳补的能力

- `WebViewAssetLoader` 固定 `https://appassets.androidplatform.net` origin，IndexedDB 与安全上下文才可用（不能用 `file://`）
- 麦克风授权、`<input type=file>` 文件选择、ZIP 导出改走 SAF 落盘（WebView 会静默丢弃 `blob:` 的 `<a download>`）
- `window.open` / `target=_blank` / 普通外链统一用 Custom Tabs
- 返回键优先关弹层再退出；状态栏字色随页面主题反色；安全区与输入法由容器留白，不 double

## 安装

```bash
adb install -r DeepSeekChatBot-v0.1.0-release.apk
```

首次启动在「设置 → 数据管理」填入自己的 DeepSeek API Key；Key 只写在本机 WebView 的 localStorage，不进云备份。

## 已知限制

- 后台 / 锁屏时 WebView 被系统节流，长时间生成可能中断（未实现前台服务）
- 运行中切换系统深浅色需重启应用；应用内「设置 → 主题」即时生效
