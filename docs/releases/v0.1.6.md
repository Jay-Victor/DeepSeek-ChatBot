把 [deepseek-ai/chat-demo](https://github.com/deepseek-ai/chat-demo) 0.1.1 装进 Android 的第七个可安装版本：修复移动端搜索框聚焦时键盘弹出的一帧闪烁，并收窄「关于」页的更新卡片、去掉多余提示。

## 应用

- 包名 `com.deepseekchatbot`，`versionCode 7`
- minSdk 26 / targetSdk 36 / compileSdk 36
- Release APK 5.32 MB，v2 签名

## 功能（来自上游）

多会话与自动标题、编辑提问 / 重新生成 / 消息分支、流式回答、深度思考、智能搜索与来源引用、附件上传（粘贴与拖拽）、语音输入与朗读、Markdown / 代码高亮 / KaTeX 公式 / Mermaid 图表、中英文、浅色深色、ZIP 历史导入导出。

## 壳补的能力

- 移动端搜索框聚焦、键盘弹出时不再闪一下：原生壳已经按输入法 inset 缩短 WebView，页面不再重复按 `visualViewport` 缩短固定层，避免两者先后收缩之间露出一帧底色
- 「关于」页的更新卡片去掉「安装前校验签名与版本号…」提示，宽度收窄到 288px 并计入内边距，手机上不再顶满两侧
- 其余沿用 v0.1.0–v0.1.5：移动端会话搜索、底部浮动「新建」、会话顶栏常驻新建、应用内下载安装更新、输入框上下文占用环、思考内容自动折叠、固定 `appassets` origin、麦克风授权、文件选择、ZIP 导出走 SAF、Custom Tabs 外链、返回键分层退出、状态栏反色、安全区与键盘避让、推挤式侧边栏

## 安装

```bash
adb install -r DeepSeekChatBot-v0.1.6-release.apk
```

首次启动在「设置 → 数据管理」填入自己的 DeepSeek API Key；Key 只存本机 WebView 的 localStorage，不进云备份。

## 已知限制

- 本版对搜索框闪烁的修复在代码与 390×844 视口模拟中验证；不同输入法的键盘动画仍建议在真机上再确认
- 会话搜索只在移动端侧边栏；桌面端保持原来的全宽新建按钮与列表
- 搜索范围是标题、当前分支正文与附件名，不包含思考内容；首次搜索要建本地索引，历史很多时会有短暂延迟
- 后台 / 锁屏时 WebView 被系统节流，长时间生成可能中断（未实现前台服务）
- 运行中切换系统深浅色需重启应用；应用内「设置 → 主题」即时生效
- 应用内更新需要访问 GitHub 资产；受限网络可能下载失败，此时可用「在浏览器中下载」
- 更新检查与资产下载依赖 GitHub 公开 API，未登录限流 60 次/小时/IP

## English

Seventh installable build of chat-demo 0.1.1 in a thin Kotlin WebView shell. This release fixes a one-frame flash when the keyboard opens while focusing the mobile sidebar search: the native shell already resizes the WebView for the IME inset, so the page no longer shrinks its fixed layer again via `visualViewport`. The About page's update card drops the redundant verification hint and is narrowed to 288px. Everything from v0.1.0–v0.1.5 is retained, including mobile session search, the floating New button, the persistent header new-chat action, in-app update installation, the 1M context-usage ring, SAF export, Custom Tabs and three-level back handling. Bring your own DeepSeek API key (stored locally only, excluded from cloud backup). Install with `adb install -r`; minSdk 26. MIT licensed, upstream notice kept in `web/LICENSE`.

Details: [README](https://github.com/Jay-Victor/DeepSeek-ChatBot/blob/main/README.md)
