v0.1.20 为会话页补上消息定位条、双击标题回顶与「回到底部」按钮，把 chat-demo 打包成的 Android 版本，第 21 个可安装版本。

## 应用

- 包名 `com.deepseekchatbot`，`versionCode 21`
- minSdk 26 / targetSdk 36 / compileSdk 36
- Release APK 5.37 MB，v2 签名

## 本版变更

- 会话页右侧新增消息定位条：提问用大点、回答用小刻度，消息密度过高时自动只保留提问点；当前视口以滑块显示
- 定位条支持点按跳到最近一条消息、拖动轨道快速滚动，桌面悬停 / 移动端拖动时显示「提问 / 回答 + 内容摘要」预览；跳到当前最后一条会回到底部并恢复流式跟底
- 双击会话标题回到最早的消息（桌面双击、移动端双击均可；Android WebView 不依赖 `dblclick`）
- 滚动离开底部后，消息区右下角出现「回到底部」浮动按钮，桌面悬停显示提示，点击平滑回底并恢复跟底
- 短会话或内容不可滚动时不显示定位条；桌面端保留原生滚动条，定位条位于其左侧

## 功能（来自上游）

多会话与自动标题、编辑提问 / 重新生成 / 消息分支、流式回答、深度思考、智能搜索与来源引用、附件上传、语音输入与朗读、Markdown / 代码高亮 / KaTeX / Mermaid、中英文、浅色深色、ZIP 历史导入导出。

## 壳补的能力

- 返回键、状态栏配色、安全区与键盘避让、麦克风、文件选择、SAF 下载、附件打开、Custom Tabs 外链、应用内更新等沿用 v0.1.0–v0.1.19
- 本版只改 Web 层，原生无新增权限或接口；定位条高度按消息区可视高度扣掉输入框，键盘弹出时自动缩短

## 安装

```bash
adb install -r DeepSeekChatBot-v0.1.20-release.apk
```

首次启动在「设置 → 数据管理」填写自己的 API Key；Key 只存本机 WebView 的 localStorage，不进云备份。

## 已知限制

- 定位条只在内容可滚动且至少有 3 条可见消息时显示；消息密度过高时只保留提问点，不再显示回答刻度
- 悬停 / 拖动预览只显示文字摘要，不加载图片或附件
- 双击回顶与定位条按当前分支实际渲染的消息计算；跳到历史位置后会暂停流式跟底，直到回到底部或点按最后一条
- 桌面端保留原生滚动条；定位条是额外的导航层，不替代滚动条拖动
- 其余限制沿用 v0.1.19（自定义端点需 HTTPS + CORS、非 DeepSeek 协议只支持纯文本 + 思考、语音只走 DeepSeek 官方端点等）

## English

v0.1.20 adds a message navigator to the chat view: question dots and answer ticks on a right-edge rail (ticks drop out on dense chats), tap-to-jump, drag-to-scrub and text previews. Double-tap the chat title to return to the earliest message, and a floating Back to bottom button appears once you leave the bottom. The navigator only shows on scrollable chats with at least 3 visible messages; the desktop build keeps the native scrollbar. No new native permissions or APIs. minSdk 26, MIT licensed, upstream notice kept in `web/LICENSE`.
