把 [deepseek-ai/chat-demo](https://github.com/deepseek-ai/chat-demo) 0.1.1 装进 Android 的第六个可安装版本：移动端侧边栏改为会话搜索 + 底部浮动新建，会话顶栏的新建按钮改为常驻，并保留 v0.1.4 的应用内更新与之前的全部壳能力。

## 应用

- 包名 `com.deepseekchatbot`，`versionCode 6`
- minSdk 26 / targetSdk 36 / compileSdk 36
- Release APK 5.32 MB，v2 签名

## 功能（来自上游）

多会话与自动标题、编辑提问 / 重新生成 / 消息分支、流式回答、深度思考、智能搜索与来源引用、附件上传（粘贴与拖拽）、语音输入与朗读、Markdown / 代码高亮 / KaTeX 公式 / Mermaid 图表、中英文、浅色深色、ZIP 历史导入导出。

## 壳补的能力

- 移动端侧边栏顶部新增会话搜索：按标题与当前分支正文（含附件名）匹配，结果带命中片段与关键词高亮，点击直接打开会话并关闭抽屉；首次搜索在本地逐条建立正文索引，之后按更新时间增量补齐，导入历史后自动失效
- 移动端侧边栏底部新增 148×48 的浮动「新建」胶囊，替代原来的全宽新建按钮；会话顶栏右侧的新建按钮改为常驻（欢迎页、加载页、会话页都显示，沿用原来的聊天气泡加号图标）
- 其余沿用 v0.1.0–v0.1.4：应用内下载并安装更新、输入框上下文占用环、思考内容自动折叠、固定 `appassets` origin、麦克风授权、文件选择、ZIP 导出走 SAF、Custom Tabs 外链、返回键分层退出、状态栏反色、安全区与键盘避让、推挤式侧边栏

## 安装

```bash
adb install -r DeepSeekChatBot-v0.1.5-release.apk
```

首次启动在「设置 → 数据管理」填入自己的 DeepSeek API Key；Key 只存本机 WebView 的 localStorage，不进云备份。

## 已知限制

- 会话搜索目前只在移动端侧边栏；桌面端保持原来的全宽新建按钮与列表
- 搜索范围是标题、当前分支正文与附件名，不包含思考内容；首次搜索要建本地索引，历史很多时会有短暂延迟
- 移动端侧边栏按 390×844 视口验证；不同输入法的拼音组合行为建议在真机上再确认
- 后台 / 锁屏时 WebView 被系统节流，长时间生成可能中断（未实现前台服务）
- 运行中切换系统深浅色需重启应用；应用内「设置 → 主题」即时生效
- 应用内更新需要访问 GitHub 资产；受限网络可能下载失败，此时可用「在浏览器中下载」
- 更新检查与资产下载依赖 GitHub 公开 API，未登录限流 60 次/小时/IP

## English

Sixth installable build of chat-demo 0.1.1 in a thin Kotlin WebView shell. On mobile, the sidebar now opens with a local session search (titles plus the current branch's text and attachment names, with highlighted hits) and ends with a floating New button; the session header's new-chat button is always visible on the welcome, loading and conversation screens. The desktop sidebar is unchanged. Everything from v0.1.0–v0.1.4 is retained, including in-app update installation, the 1M context-usage ring, thinking collapse, the fixed `appassets` origin, SAF export, Custom Tabs and three-level back handling. Bring your own DeepSeek API key (stored locally only, excluded from cloud backup). Install with `adb install -r`; minSdk 26. MIT licensed, upstream notice kept in `web/LICENSE`.
