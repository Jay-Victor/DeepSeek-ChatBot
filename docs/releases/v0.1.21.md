v0.1.21 在「设置 → 关于」加入支持作者与收款码保存到相册，把 chat-demo 打包成的 Android 版本，第 22 个可安装版本。

## 应用

- 包名 `com.deepseekchatbot`，`versionCode 22`
- minSdk 26 / targetSdk 36 / compileSdk 36
- Release APK 5.63 MB，v2 签名

## 本版变更

- 关于页底部新增「支持作者」：展示微信支付 / 支付宝收款码海报，点按进入应用内全屏预览（再点图片可切原始尺寸）
- 新增「保存到相册」：原生 `GallerySaver` 把海报写入 `Pictures/DeepSeek ChatBot`；Android 10+ 不需要存储权限，8/9 首次保存时申请 `WRITE_EXTERNAL_STORAGE`
- 保存完成提示「已保存到相册」；重复保存由系统自动加序号，不覆盖旧图
- README 中英增加「支持作者（为爱发电）」小节与收款码
- 打赏完全自愿，不影响任何功能与更新；应用不接支付 SDK、不校验转账结果

## 功能（来自上游）

多会话与自动标题、编辑提问 / 重新生成 / 消息分支、流式回答、深度思考、智能搜索与来源引用、附件上传、语音输入与朗读、Markdown / 代码高亮 / KaTeX / Mermaid、中英文、浅色深色、ZIP 历史导入导出。

## 壳补的能力

- 返回键、状态栏配色、安全区与键盘避让、麦克风、文件选择、SAF 下载、附件打开、Custom Tabs 外链、应用内更新等沿用 v0.1.0–v0.1.20
- 本版原生新增 `GallerySaver` 与 `WRITE_EXTERNAL_STORAGE`（仅 `maxSdkVersion=28`）：Android 10+ 走 MediaStore 的 `RELATIVE_PATH` + `IS_PENDING`，不申请存储权限；8/9 显式写 `DATA` 并在首次保存时请求权限

## 安装

```bash
adb install -r DeepSeekChatBot-v0.1.21-release.apk
```

首次启动在「设置 → 数据管理」填写自己的 API Key；Key 只存本机 WebView 的 localStorage，不进云备份。

## 已知限制

- 收款码是静态图片：应用不接入支付 SDK、不校验转账结果；换码需要发新版本，旧版本仍显示旧码
- 保存的是整张海报（含支付方式与收款人昵称），不是裁剪后的纯二维码
- Android 8/9 的旧存储权限分支未在 8/9 实机验证；浏览器里的保存回退为普通下载，未单独验证
- 其余限制沿用 v0.1.20（消息定位条只在可滚动会话显示、后台长时间生成可能中断、自定义端点需 HTTPS + CORS 等）

## English

v0.1.21 adds a Support the author card at the bottom of Settings → About with WeChat Pay and Alipay tip posters. Tap one for the full-screen viewer, or save it to the system gallery under `Pictures/DeepSeek ChatBot` and pick it from the gallery in WeChat or Alipay — Android 10+ needs no storage permission, 8/9 asks for `WRITE_EXTERNAL_STORAGE` on the first save. Tips are voluntary and unlock nothing; the app does not integrate a payment SDK or verify transfers. Android 16 emulator verification covered rendering in both locales, the viewer and Back handling, byte-identical saves, and jsQR decoding of the displayed codes; the Android 8/9 permission branch was not device-tested. minSdk 26, MIT licensed, upstream notice kept in `web/LICENSE`.
