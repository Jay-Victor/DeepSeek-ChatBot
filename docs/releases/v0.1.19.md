v0.1.19 把 App 的 API 接入从单一 DeepSeek 端点扩展为多方案，把 chat-demo 打包成的 Android 版本，第 20 个可安装版本。

## 应用

- 包名 `com.deepseekchatbot`，`versionCode 20`
- minSdk 26 / targetSdk 36 / compileSdk 36
- Release APK 5.36 MB，v2 签名

## 本版变更

- 设置 → 数据管理新增「接入方案」：可保存多套端点（DeepSeek / Anthropic / OpenAI 兼容）、各自的 API Key 与默认模型，随时切换当前方案
- 输入端点与 API Key 后可获取模型列表：DeepSeek 读取 `/models` 的上下文窗口、输出上限、图片能力与 effort；Anthropic 读取 `/v1/models`；OpenAI 兼容读取 `/v1/models`；没有列表时允许手动填写模型 ID
- 默认 DeepSeek 端点同样支持获取模型列表与切换 `deepseek-flash` / `deepseek-v4-pro`
- 会话级绑定：新会话记录创建时的方案与模型，之后切换当前方案不会改变旧会话的请求目标；方案被删除时旧会话回落到当前方案
- 深度思考 / 智能搜索按协议与模型能力门控：不支持时置灰并保留用户偏好；请求构建时静默去掉不支持的字段，历史里的 DeepSeek 工具块与非 DeepSeek 协议的 `latest_reminder` 自动剥离
- 上下文窗口按模型元数据换算，占用环、压缩预览与自动压缩预算同步；占用卡片显示当前方案与模型
- 非 DeepSeek 端点使用首条提问生成本地标题；无视觉模型（如 `deepseek-v4-pro`）只保留文档附件入口
- 欢迎页显示当前接入方案与模型，点击直接进入「设置 → 数据管理」
- 旧版本的单 API Key 自动迁移成默认「DeepSeek 官方」方案，旧键保留以便回滚

## 功能（来自上游）

多会话与自动标题、编辑提问 / 重新生成 / 消息分支、流式回答、深度思考、智能搜索与来源引用、附件上传、语音输入与朗读、Markdown / 代码高亮 / KaTeX / Mermaid、中英文、浅色深色、ZIP 历史导入导出。

## 壳补的能力

- 返回键、状态栏配色、安全区与键盘避让、麦克风、文件选择、SAF 下载、附件打开、Custom Tabs 外链、应用内更新等沿用 v0.1.0–v0.1.18
- 本版只改 Web 层与接入配置，原生无新增权限或接口；语音输入与朗读仍只调用 DeepSeek 官方 `/v1/tools`，自定义 DeepSeek 端点不转发该路径时会自动隐藏语音入口

## 安装

```bash
adb install -r DeepSeekChatBot-v0.1.19-release.apk
```

首次启动在「设置 → 数据管理」填写自己的 API Key；Key 只存本机 WebView 的 localStorage，不进云备份。

## 已知限制

- 自定义端点必须允许跨域（CORS）且使用 https；不满足时请求会在 WebView 内失败；地址填 API 根，不要带 `/v1` 或 `/anthropic`
- 非 DeepSeek 协议第一版只支持纯文本 + 思考：智能搜索、附件、语音输入与服务端自动标题按能力降级；Anthropic / OpenAI 端点下这些入口会隐藏或置灰
- 语音输入与朗读仍只调用 DeepSeek 官方 `/v1/tools`；自定义 DeepSeek 端点不转发该路径时会自动隐藏语音入口
- 上下文占用仍按 DeepSeek-V4 分词器估算，其他模型的数字是近似值
- 接入方案是设备级设置，不随 ZIP 导出 / 导入迁移；导入的会话回落到当前方案
- `deepseek-v4-pro` 不支持图片输入，只能添加文档附件；`deepseek-flash` 支持图片
- 自定义端点没有 `/models` 时需要手动填写模型 ID；模型能力按协议与 ID 推断
- 应用内更新需要访问 GitHub 资产；受限网络可能下载失败，此时可用「在浏览器中下载」

## English

v0.1.19 adds API profiles: store multiple DeepSeek / Anthropic / OpenAI-compatible endpoints with their own keys, fetch models and switch the default model. New chats bind to the profile and model they were created with, so changing the current profile never retargets old chats. Thinking, web search, attachments, speech and server-side titles are gated by protocol and model capability, with DeepSeek-only extensions stripped from other protocols. Context-window math, compression previews and the usage ring follow the bound model. Custom endpoints must allow CORS and use HTTPS; non-DeepSeek protocols are text + thinking only in this version. minSdk 26, MIT licensed, upstream notice kept in `web/LICENSE`.
