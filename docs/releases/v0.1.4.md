把 [deepseek-ai/chat-demo](https://github.com/deepseek-ai/chat-demo) 0.1.1 装进 Android 的第五个可安装版本：新增应用内下载并安装更新，并保留 v0.1.3 的上下文占用环与之前的全部壳能力。

## 应用

- 包名 `com.deepseekchatbot`，`versionCode 5`
- minSdk 26 / targetSdk 36 / compileSdk 36
- Release APK 5.32 MB，v2 签名

## 功能（来自上游）

多会话与自动标题、编辑提问 / 重新生成 / 消息分支、流式回答、深度思考、智能搜索与来源引用、附件上传（粘贴与拖拽）、语音输入与朗读、Markdown / 代码高亮 / KaTeX 公式 / Mermaid 图表、中英文、浅色深色、ZIP 历史导入导出。

## 壳补的能力

- 「设置 → 关于」支持应用内下载并安装更新：显示安装包大小与下载进度，可取消；下载完成后校验字节数、SHA-256、包名、签名证书与 versionCode，再交给系统安装器覆盖安装
- 更新包优先从 GitHub API 资产入口下载，受限网络下比 `github.com` 直链更容易走通；失败时可在浏览器中打开 Release 资产
- 首次安装会引导开启「未知来源」权限，返回应用后自动继续；安装器被取消时会恢复为可重试状态
- 输入框上下文占用环：按 DeepSeek-V4 分词器统计当前分支文本，1M 窗口，回合结束后更新，服务端 `usage` 校准模板与附件开销
- 其余沿用 v0.1.0–v0.1.3：固定 `appassets` origin、麦克风授权、文件选择、ZIP 导出走 SAF、Custom Tabs 外链、返回键分层退出、状态栏反色、安全区与键盘避让、思考内容自动折叠、输入框单按钮、推挤式侧边栏、关于页更新检查

## 安装

```bash
adb install -r DeepSeekChatBot-v0.1.4-release.apk
```

首次启动在「设置 → 数据管理」填入自己的 DeepSeek API Key；Key 只存本机 WebView 的 localStorage，不进云备份。

## 已知限制

- 应用内更新需要访问 GitHub 资产；受限网络可能下载失败，此时可用卡片里的「在浏览器中下载」，首次安装还需在系统设置里允许未知来源
- 下载期间请保持应用在前台；进程被系统回收后需要重新下载
- 1M 窗口下普通会话占比很低；上下文环使用 2% 最小可见弧度，精确数值以点击后的详情为准
- 后台 / 锁屏时 WebView 被系统节流，长时间生成可能中断（未实现前台服务）
- 运行中切换系统深浅色需重启应用；应用内「设置 → 主题」即时生效
- 更新检查与资产下载依赖 GitHub 公开 API，未登录限流 60 次/小时/IP；触发限流时「关于」页会提示失败，可稍后重试

## English

Fifth installable build of chat-demo 0.1.1 in a thin Kotlin WebView shell. This release adds in-app update download and installation: Settings → About shows the APK size and progress, can cancel, then verifies length, SHA-256, package name, signing certificate and versionCode before handing the file to the system installer. Downloads prefer the `api.github.com` release-asset endpoint (the `github.com` direct link can reset on restricted networks), with a browser fallback. The first install asks for the unknown-sources permission and continues on return. The context-usage ring, thinking-collapse switch, single voice/send/stop button, push-style mobile sidebar, and About-page update checks from earlier releases are retained. Bring your own DeepSeek API key (stored locally only, excluded from cloud backup). Install with `adb install -r`; minSdk 26. MIT licensed, upstream notice kept in `web/LICENSE`.
