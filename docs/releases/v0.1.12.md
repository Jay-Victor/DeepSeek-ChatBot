v0.1.12 是一个修复版本：聊天页面不再能被双指放大，其余功能与 v0.1.11 相同。

## 应用

- 包名 `com.deepseekchatbot`，`versionCode 13`
- minSdk 26 / targetSdk 36 / compileSdk 36
- Release APK 5.34 MB，v2 签名

## 本版修复

- 聊天页面可以被双指放大：viewport 增加 `maximum-scale=1,user-scalable=no`，并在 WebView 设置 `setSupportZoom(false)`
- 原因：原来只关闭了 `builtInZoomControls` / `displayZoomControls`，它们只隐藏缩放控件，`supportZoom` 默认仍为 `true`，pinch 手势继续生效
- 应用内图片预览的「点按切换原始尺寸」是自绘交互，不受影响
- 系统辅助功能里的「强制启用缩放」仍属于系统级无障碍能力，应用无法关闭

## 功能（来自上游）

多会话与自动标题、编辑提问 / 重新生成 / 消息分支、流式回答、深度思考、智能搜索与来源引用、附件上传、语音输入与朗读、Markdown / 代码高亮 / KaTeX / Mermaid、中英文、浅色深色、ZIP 历史导入导出。

## 壳补的能力

- 语音输入：圆圈声波入口、按住说话、录音浮层、上滑取消、松手转写并直接发送
- 添加附件：圆圈加号展开最近照片与拍照 / 相册 / 文件面板
- 更新提示：整条可点，直接打开「设置 → 关于」
- 附件打开、SAF 下载、Custom Tabs 外链、返回键分层退出、状态栏反色、安全区与键盘避让等沿用 v0.1.0–v0.1.11

## 安装

```bash
adb install -r DeepSeekChatBot-v0.1.12-release.apk
```

首次启动在「设置 → 数据管理」填入自己的 DeepSeek API Key；Key 只存本机 WebView 的 localStorage，不进云备份。

## 已知限制

- 系统辅助功能的「强制启用缩放」仍可放大页面，这是系统无障碍行为
- 最近照片需要相册权限；拒绝后照片条显示重试，拍照 / 相册 / 文件仍可用
- 后台 / 锁屏时 WebView 被系统节流，长时间生成可能中断
- 应用内更新需要访问 GitHub 资产；受限网络可能下载失败，此时可用「在浏览器中下载」

## English

Patch release on top of v0.1.11: page-level pinch zoom is disabled by adding `maximum-scale=1,user-scalable=no` to the viewport and calling `setSupportZoom(false)` on the WebView. `builtInZoomControls = false` alone only hides the zoom widget and left pinch gestures enabled. The in-app image preview's tap-to-actual-size is unaffected, and Android's accessibility "force enable zoom" remains a system-level capability. All v0.1.11 features are retained. Bring your own DeepSeek API key (stored locally only, excluded from cloud backup). Install with `adb install -r`; minSdk 26. MIT licensed, upstream notice kept in `web/LICENSE`.
