v0.1.15 把移动端设置分组改为横向滚动，替换 v0.1.14 的两行网格布局。

## 应用

- 包名 `com.deepseekchatbot`，`versionCode 16`
- minSdk 26 / targetSdk 36 / compileSdk 36
- Release APK 5.34 MB，v2 签名

## 本版变更

- 设置弹窗的四个分组改为单行横向滚动：每项按「图标 + 文字 + 内边距」的实际内容宽度排列，`flex: 0 0 auto`，不再被压缩到内容宽度以下
- 长标签保持单行；字号变大或屏幕更窄时，整条导航可以左右滑动，不会换行、不会与相邻项重叠
- 图标不收缩；隐藏滚动条，右侧保留未完整显示的分组作为可滑动提示；支持 `scroll-snap`
- 桌面端左侧竖排导航不变，设置内容区不变
- 验证：390×844 视口下以 14 / 16 / 22px 字号复验，分组之间均保留 4px 间距、无重叠；22px 时可横向滚动到「关于」并切换
- 其余功能与 v0.1.14 相同

## 功能（来自上游）

多会话与自动标题、编辑提问 / 重新生成 / 消息分支、流式回答、深度思考、智能搜索与来源引用、附件上传、语音输入与朗读、Markdown / 代码高亮 / KaTeX / Mermaid、中英文、浅色深色、ZIP 历史导入导出。

## 壳补的能力

- 上下文与压缩、占用卡片、消息列表分隔条沿用 v0.1.13，本次仅调整移动端设置导航布局
- 返回键、状态栏配色、安全区与键盘避让、麦克风、文件选择、SAF 下载、附件打开、Custom Tabs 外链、应用内更新等沿用 v0.1.0–v0.1.14

## 安装

```bash
adb install -r DeepSeekChatBot-v0.1.15-release.apk
```

首次启动在「设置 → 数据管理」填入自己的 DeepSeek API Key；Key 只存本机 WebView 的 localStorage，不进云备份。

## 已知限制

- 四个分组超出一屏时需要横向滑动；滚动条被隐藏，最后一个分组可能只露出部分，作为可滑动的提示
- 压缩摘要会产生额外的模型请求；压缩目标是软目标，最近一轮本身过大时可能达不到
- 压缩只保留单条记录：在覆盖点之前切分支会让摘要失效；在另一条分支再压缩会覆盖前一条
- ZIP 导入导出不携带压缩摘要，导入后回到完整上下文

## English

v0.1.15 replaces the 2×2 mobile settings grid with a horizontal scroll strip. Each tab keeps its content width, so larger text or longer labels scroll sideways instead of wrapping or overlapping. Icons never shrink, the scrollbar is hidden, and a partially visible tab hints that the strip can be swiped; desktop navigation is unchanged. Verified at 390×844 with 14 / 16 / 22px text without overlap, including scrolling to About at 22px. Compression and the shell capabilities are unchanged from v0.1.14. Install with `adb install -r`; minSdk 26, MIT licensed, upstream notice kept in `web/LICENSE`.
