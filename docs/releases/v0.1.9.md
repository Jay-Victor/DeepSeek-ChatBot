把 [deepseek-ai/chat-demo](https://github.com/deepseek-ai/chat-demo) 0.1.1 装进 Android 的第十个可安装版本：会话页支持自动朗读，会话菜单支持置顶与多选。

## 应用

- 包名 `com.deepseekchatbot`，`versionCode 10`
- minSdk 26 / targetSdk 36 / compileSdk 36
- Release APK 5.32 MB，v2 签名

## 功能（来自上游）

多会话与自动标题、编辑提问 / 重新生成 / 消息分支、流式回答、深度思考、智能搜索与来源引用、附件上传（粘贴与拖拽）、语音输入与朗读、Markdown / 代码高亮 / KaTeX 公式 / Mermaid 图表、中英文、浅色深色、ZIP 历史导入导出。

## 壳补的能力

- 会话页顶栏「新建」左侧新增自动朗读开关：开启后每条新完成的回复自动朗读一次；关闭会停止当前朗读；状态保存在本机，重开应用仍保留
- 开关切换时在屏幕中央显示 1.6 秒的「已开启自动朗读 / 已关闭自动朗读」提示
- 自动朗读只读当前会话、前台完成且未被停止或出错的回复；正在朗读其他内容时不打断，留给用户手动点读
- 移动端会话三点菜单新增「置顶 / 取消置顶」：直接写入本地并进入「置顶」分组，置顶状态随 ZIP 导入导出保留
- 同一菜单新增「多选」：进入选择模式并预选当前会话，可继续勾选后批量置顶 / 删除
- 其余沿用 v0.1.0–v0.1.8：移动端会话搜索、底部浮动「新建」、会话顶栏常驻新建、应用内下载安装更新、输入框上下文占用环、思考内容自动折叠、固定 `appassets` origin、麦克风授权、文件选择、ZIP 导出走 SAF、Custom Tabs 外链、返回键分层退出、状态栏反色、安全区与键盘避让、推挤式侧边栏、多选批量置顶 / 删除

## 安装

```bash
adb install -r DeepSeekChatBot-v0.1.9-release.apk
```

首次启动在「设置 → 数据管理」填入自己的 DeepSeek API Key；Key 只存本机 WebView 的 localStorage，不进云备份。

## 已知限制

- 自动朗读会为每条完成的回复调用一次 TTS 接口，产生对应计费；默认关闭
- 自动朗读只针对当前会话、前台完成的回复；正在朗读其他内容时会跳过本次
- 置顶与多选入口仍只在移动端；桌面端保持原样
- 后台 / 锁屏时 WebView 被系统节流，长时间生成可能中断（未实现前台服务）
- 运行中切换系统深浅色需重启应用；应用内「设置 → 主题」即时生效
- 应用内更新需要访问 GitHub 资产；受限网络可能下载失败，此时可用「在浏览器中下载」
- 更新检查与资产下载依赖 GitHub 公开 API，未登录限流 60 次/小时/IP

## English

Tenth installable build of chat-demo 0.1.1 in a thin Kotlin WebView shell. The session header gains an auto-read toggle: when enabled, every completed reply is read aloud once, with a 1.6-second centered status pill and a persisted setting. Auto-read only fires for the active chat while the app is in the foreground, skips stopped or failed replies, never interrupts an ongoing reading, and makes one billed TTS request per completed reply. The mobile session menu now offers pin/unpin (writes locally and moves the chat into a Pinned group) and multi-select (enters selection mode with the current chat selected). Everything from v0.1.0–v0.1.8 is retained, including session search, in-app updates, the context ring, SAF export, Custom Tabs and three-level back handling. Bring your own DeepSeek API key (stored locally only, excluded from cloud backup). Install with `adb install -r`; minSdk 26. MIT licensed, upstream notice kept in `web/LICENSE`.
