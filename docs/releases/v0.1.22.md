v0.1.22 让朗读可以改用本地系统文字转语音（离线、免费），把 chat-demo 打包成的 Android 版本，第 23 个可安装版本。

## 应用

- 包名 `com.deepseekchatbot`，`versionCode 23`
- minSdk 26 / targetSdk 36 / compileSdk 36
- Release APK 5.64 MB，v2 签名

## 本版变更

- 设置 → 通用新增「朗读方式」：在线（DeepSeek 的 stella / tide 音色）或本地（系统文字转语音）；默认仍为在线，老用户行为不变
- 本地朗读新增 0.5–2.0 倍语速与试听按钮，切换引擎会立即停止当前朗读
- 本地朗读前把回复正文清洗成纯文本：代码块、表格、公式、图片与裸链接默认跳过，链接只读文字
- 本地引擎让朗读不再依赖 DeepSeek 官方端点：自定义端点、Anthropic 与 OpenAI 方案下朗读按钮与自动朗读开关也可用
- 原生新增 `TtsSpeaker`：`TextToSpeech` 懒初始化、按标点分段（≤600 字）、瞬态音频焦点、`__onSpeech` 进度回传；Manifest 声明 `TTS_SERVICE` 的 `<queries>`（Android 11+ 才能发现系统引擎）

## 功能（来自上游）

多会话与自动标题、编辑提问 / 重新生成 / 消息分支、流式回答、深度思考、智能搜索与来源引用、附件上传、语音输入与朗读、Markdown / 代码高亮 / KaTeX / Mermaid、中英文、浅色深色、ZIP 历史导入导出。

## 壳补的能力

- 返回键、状态栏配色、安全区与键盘避让、麦克风、文件选择、SAF 下载、附件打开、Custom Tabs 外链、应用内更新等沿用 v0.1.0–v0.1.21
- 本版原生新增 `TtsSpeaker` 与 `speak` / `stopSpeak` 桥：长文本分段播放、`UtteranceProgressListener` 回传 start / done / error，页面按 token 丢弃停止后的迟到回调
- 在线朗读（流式 PCM + AudioContext）保持原实现，仅把朗读入口拆成两个后端

## 安装

```bash
adb install -r DeepSeekChatBot-v0.1.22-release.apk
```

首次启动在「设置 → 数据管理」填写自己的 API Key；Key 只存本机 WebView 的 localStorage，不进云备份。

## 已知限制

- 本地朗读的音色、停顿与可用语速由机型语音引擎决定；缺少当前语言的语音数据时，需要在系统「文字转语音」里安装
- 本地朗读只读当前语言的正文：代码块、表格、公式、图片与裸链接不读
- 模拟器 Google TTS 首次合成中文报过 `ERROR_NETWORK`（-7，缺离线语音包），安装语音数据后正常；真机听感与厂商引擎待设备验收
- 其余限制沿用 v0.1.21（在线朗读计费、后台长时间生成可能中断、自定义端点需 HTTPS + CORS 等）

## English

v0.1.22 lets read-aloud use the device text-to-speech engine instead of the DeepSeek TTS endpoint. Settings → General now offers Online (the stella / tide voices) or Local (system TTS) with a 0.5–2.0× speed slider and a preview button; Online remains the default. Local reading strips markdown first — code blocks, tables, formulas, images and bare URLs are skipped — works offline, makes no TTS request, and is also available on custom, Anthropic and OpenAI profiles. A new native `TtsSpeaker` splits long replies into chunks, reports start / done / error over `__onSpeech`, and the manifest declares the `TTS_SERVICE` query for Android 11+. Android 16 emulator verification covered chunked playback, stop / restart, text cleaning, the settings controls, auto-read on a mocked reply, and capability gating on a non-DeepSeek profile; real-device audio is still to be checked. minSdk 26, MIT licensed, upstream notice kept in `web/LICENSE`.
