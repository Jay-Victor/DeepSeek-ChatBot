把 [deepseek-ai/chat-demo](https://github.com/deepseek-ai/chat-demo) 0.1.1 装进 Android 的第九个可安装版本：移动端侧边栏新增多选，支持批量置顶与删除。

## 应用

- 包名 `com.deepseekchatbot`，`versionCode 9`
- minSdk 26 / targetSdk 36 / compileSdk 36
- Release APK 5.32 MB，v2 签名

## 功能（来自上游）

多会话与自动标题、编辑提问 / 重新生成 / 消息分支、流式回答、深度思考、智能搜索与来源引用、附件上传（粘贴与拖拽）、语音输入与朗读、Markdown / 代码高亮 / KaTeX 公式 / Mermaid 图表、中英文、浅色深色、ZIP 历史导入导出。

## 壳补的能力

- 移动端侧边栏新增多选：列表右上角入口进入选择模式，顶部显示「选择对话 / 已选择 N 个对话」，每行带圆形勾选框，底部出现「置顶 / 删除」操作栏
- 批量置顶：确认后写入本地并新增「置顶」分组，刷新或重开应用仍保留；ZIP 导入导出沿用归档里已有的 `pinned` 字段，换机迁移不丢
- 批量删除：确认弹窗提示不可恢复，逐条删除；有失败时保留未删项并提示
- 确认弹窗：置顶为居中的「取消 / 置顶」双按钮，删除为标题 + 说明 + 全宽红色「删除」+ 取消
- 其余沿用 v0.1.0–v0.1.7：移动端会话搜索、底部浮动「新建」、会话顶栏常驻新建、应用内下载安装更新、输入框上下文占用环、思考内容自动折叠、固定 `appassets` origin、麦克风授权、文件选择、ZIP 导出走 SAF、Custom Tabs 外链、返回键分层退出、状态栏反色、安全区与键盘避让、推挤式侧边栏

## 安装

```bash
adb install -r DeepSeekChatBot-v0.1.8-release.apk
```

首次启动在「设置 → 数据管理」填入自己的 DeepSeek API Key；Key 只存本机 WebView 的 localStorage，不进云备份。

## 已知限制

- 多选只在移动端侧边栏；桌面端保持原来的全宽新建按钮与列表
- 批量删除逐条执行；某条失败时会保留该项并提示重试
- 置顶分组按会话更新时间排序，置顶本身不修改更新时间
- 后台 / 锁屏时 WebView 被系统节流，长时间生成可能中断（未实现前台服务）
- 运行中切换系统深浅色需重启应用；应用内「设置 → 主题」即时生效
- 应用内更新需要访问 GitHub 资产；受限网络可能下载失败，此时可用「在浏览器中下载」
- 更新检查与资产下载依赖 GitHub 公开 API，未登录限流 60 次/小时/IP

## English

Ninth installable build of chat-demo 0.1.1 in a thin Kotlin WebView shell. The mobile sidebar gains multi-select: a button at the top-right of the list enters selection mode, with a selection header, per-chat circular checkboxes and a bottom bar for batch pin/delete. Pinned chats move into a new Pinned group, persist locally, and survive ZIP export/import through the archive's existing `pinned` field. Batch delete asks for confirmation and removes chats one by one, keeping failures selected with an error toast. Both actions use dedicated confirmation dialogs. Everything from v0.1.0–v0.1.7 is retained, including mobile session search, the floating New button, in-app updates, the context ring, SAF export, Custom Tabs and three-level back handling. Bring your own DeepSeek API key (stored locally only, excluded from cloud backup). Install with `adb install -r`; minSdk 26. MIT licensed, upstream notice kept in `web/LICENSE`.
