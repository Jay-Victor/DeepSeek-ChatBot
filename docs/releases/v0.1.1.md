把 [deepseek-ai/chat-demo](https://github.com/deepseek-ai/chat-demo) 0.1.1 装进 Android 的第二个可安装版本：输入框合并为单按钮、移动端侧边栏改为推挤式抽屉，并新增「设置 → 关于」与 GitHub Release 更新检查。

## 应用

- 包名 `com.deepseekchatbot`，`versionCode 2`
- minSdk 26 / targetSdk 36 / compileSdk 36
- Release APK 4.60 MB，v2 签名

## 功能（来自上游）

多会话与自动标题、编辑提问 / 重新生成 / 消息分支、流式回答、深度思考、智能搜索与来源引用、附件上传（粘贴与拖拽）、语音输入与朗读、Markdown / 代码高亮 / KaTeX 公式 / Mermaid 图表、中英文、浅色深色、ZIP 历史导入导出。

## 壳补的能力

- 输入框右侧合并为单按钮：无内容时是麦克风，输入后变发送，输出中变停止；录音与转写沿用原光圈、读秒和加载环
- 移动端侧边栏改为推挤式抽屉：抽屉与主内容共用一条位移，展开时主内容被推开并随进度压暗，支持全屏横向右滑打开、左滑或点按关闭
- 设置新增「关于」：应用图标、名称与版本，可从 GitHub Release 检查更新；自动检查默认开启（每次打开应用时检查一次），也可关闭
- 其余沿用 v0.1.0：固定 `appassets` origin、麦克风授权、文件选择、ZIP 导出走 SAF、Custom Tabs 外链、状态栏反色、安全区与键盘避让

## 安装

```bash
adb install -r DeepSeekChatBot-v0.1.1-release.apk
```

首次启动在「设置 → 数据管理」填入自己的 DeepSeek API Key；Key 只存本机 WebView 的 localStorage，不进云备份。

## 已知限制

- 后台 / 锁屏时 WebView 被系统节流，长时间生成可能中断（未实现前台服务）
- 运行中切换系统深浅色需重启应用；应用内「设置 → 主题」即时生效
- 更新检查依赖 GitHub 公开 API，未登录限流 60 次/小时/IP；自动检查在每次打开应用时都会请求一次，频繁打开或切回前台可能触发限流，此时「关于」页会提示检查失败，可稍后重试

Second installable build of chat-demo 0.1.1 in a thin Kotlin WebView shell: a single voice/send/stop button, a push-style mobile sidebar with swipe gestures, and an About page with GitHub Release update checks.
