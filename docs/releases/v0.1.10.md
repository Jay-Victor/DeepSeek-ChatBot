把 [deepseek-ai/chat-demo](https://github.com/deepseek-ai/chat-demo) 0.1.3 装进 Android 的第十一个可安装版本：附件可直接打开，链接只接受 HTTP(S)，超大图片上传前自动缩小。

## 应用

- 包名 `com.deepseekchatbot`，`versionCode 11`
- minSdk 26 / targetSdk 36 / compileSdk 36
- Release APK 5.33 MB，v2 签名

## 功能（来自上游）

多会话与自动标题、编辑提问 / 重新生成 / 消息分支、流式回答、深度思考、智能搜索与来源引用、附件上传（粘贴与拖拽）、语音输入与朗读、Markdown / 代码高亮 / KaTeX 公式 / Mermaid 图表、中英文、浅色深色、ZIP 历史导入导出。

本版同步 chat-demo 0.1.3：

- 草稿与聊天记录中的附件可以直接打开；支持预览的图片和 PDF 在新标签页显示，SVG 和其他文件可下载原件
- 回复中的搜索结果、引用和网页读取记录仅允许打开 HTTP 或 HTTPS 链接
- 长边超过 4096 像素的图片在上传前等比缩小；历史对话再次引用这类图片时自动补传

## 壳补的能力

- Android 没有「新标签页」：图片改为应用内全屏预览，点图片在适应屏幕 / 原始尺寸之间切换，返回键或点空白关闭
- PDF 写入应用私有缓存后交给系统查看器；没有可用查看器时提示并回退到 SAF 保存
- SVG 与其他文件复用 SAF 保存桥，按文件 MIME 创建文档（保存桥不再固定为 ZIP）
- 其余沿用 v0.1.0–v0.1.9：移动端会话搜索、底部浮动「新建」、会话顶栏常驻新建、自动朗读、应用内下载安装更新、输入框上下文占用环、思考内容自动折叠、固定 `appassets` origin、麦克风授权、文件选择、ZIP 导出走 SAF、Custom Tabs 外链、返回键分层退出、状态栏反色、安全区与键盘避让、推挤式侧边栏、多选批量置顶 / 删除

## 安装

```bash
adb install -r DeepSeekChatBot-v0.1.10-release.apk
```

首次启动在「设置 → 数据管理」填入自己的 DeepSeek API Key；Key 只存本机 WebView 的 localStorage，不进云备份。

## 已知限制

- 超过 4096 像素的动图在上传前缩放时只保留一帧，动效会丢失（上游行为）
- PDF 打开依赖系统查看器；没有可用的 PDF 应用时会弹出保存位置选择
- 后台 / 锁屏时 WebView 被系统节流，长时间生成可能中断（未实现前台服务）
- 运行中切换系统深浅色需重启应用；应用内「设置 → 主题」即时生效
- 应用内更新需要访问 GitHub 资产；受限网络可能下载失败，此时可用「在浏览器中下载」

## English

Eleventh installable build of chat-demo 0.1.3 in a thin Kotlin WebView shell. Attachments can now be opened: images use a full-screen in-app preview (tap to toggle actual size), PDFs go to the system viewer (falling back to a SAF save when no viewer exists), and SVG or other files are saved through SAF. Search results, citations and page links accept HTTP(S) only. Images whose long edge exceeds 4096 px are downscaled before upload, and historical images are re-uploaded automatically when reused. The Android WebView zero-size File quirk (SAF files read back from IndexedDB) is handled for previews, uploads and ZIP export. Bring your own DeepSeek API key (stored locally only, excluded from cloud backup). Install with `adb install -r`; minSdk 26. MIT licensed, upstream notice kept in `web/LICENSE`.
